# 🐍 My Python Mastery Roadmap

Welcome to my personal Python learning diary! I built this repository from scratch to document my coding journey, practice syntax conventions, and create an easy-to-read reference guide for future revision.

---

## 🗺️ Learning Checklist & Roadmap

This project is dynamic! As I learn new concepts, I expand this list and create corresponding folders containing executable scripts.

- [x] `01_variables_and_types` — Data primitives, type checking, and string casting operations.
- [x] `02_control_flow_and_loops` — Logical conditions, definite `for` loops, indefinite `while` loops, and loop controls (`break`/`continue`).
- [x] `03_data_structures` — Mastery of Lists, Tuples, and advanced Dictionary lookups/comprehensions.
- [x] `04_functions_and_modules` — Custom `def` structures, scope, and importing standard/external utility modules (`random`, `math`).
- [x] `05_file_handling` — Reading, writing, and appending external data files safely using context managers (`with`).
- [x] `06_object_oriented_programming` — Structural architecture using Classes, Instances, Initialization, Inheritance, and Polymorphism.
- [ ] *Next up: Exception Handling (`try/except` blocks)*
- [ ] *Next up: Working with APIs & JSON data*

---

## 📂 Repository Architecture

Each folder inside this repository is structured as follows:
* **`*.py` Files:** Clean, heavily-commented, working scripts demonstrating the core syntax rules.
* **`README.md` Files:** Micro-cheat sheets inside each folder explaining the "how" and "why" behind specific rules (like avoiding loop-return traps or using the Walrus operator `:=`).

---

## 🛠️ How to Run and Revise

To test any script locally, clone this repository, navigate to the targeted topic folder in your terminal, and run:

\`\`\`bash
python folder_name/script_name.py
\`\`\`
